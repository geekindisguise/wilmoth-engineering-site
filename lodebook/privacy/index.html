Privacy Policy — Lodebook

Last updated: October 5, 2026.

Lodebook is a field notebook for spots, finds, notes, and mining claims on iPhone, iPad, and Mac from Wilmoth Engineering, LLC. This page covers Lodebook.

What the app does

You keep spots, finds, notes, and mining claims. The map draws satellite photos and other base layers. Setup and Settings offer Local and iCloud.

You use this App Store release without an account and without signing in.

Where your records sit

Local keeps a SwiftData file on the device.

iCloud uses that same store and attaches CloudKit’s private database iCloud.com.wilmothengineering.MiningOpsCompanion. Photo and receipt bytes mirror through CloudKit in iCloud. Local and iCloud are the same records. Local is this device. iCloud is this Apple ID — backup and extra iPhone, iPad, and Mac.

Settings → Take it with you writes a zip of this device.

A background refresh can run. That refresh stays on the device and does not sign in.

Location, camera, and photos

Location is used while the app is in use: the map puck, claim detection, field-note coordinates, Stake Day, and walking a boundary. GPS Walk, while it is recording on iPhone, keeps location updates running in the background and shows the system location indicator.

The camera photographs finds, hazards, and other annotations on the map. The photo library attaches receipt images and find photos.

Tracking and collected data

Tracking is off. The tracking-domain list is empty. The collected-data-type list is empty. Lodebook includes no analytics, Firebase, Sentry, or telemetry.

Required-reason API access: UserDefaults (CA92.1), file timestamps (C617.1), and the pasteboard (3B52.1).

Network

Raster map tiles load from Esri and USGS when a fetch is allowed: Wi-Fi by default, the device online, field mode off, and Low Power Mode off. Street map uses Apple’s map. Public-land and PLSS overlay tiles load when those layers are on and a fetch is allowed. iCloud storage uses CloudKit. A link you tap, including map attribution or MLRS, opens in the browser.

Plus

Plus is an in-app purchase through the App Store (StoreKit). The price comes from the App Store. See Apple’s Privacy Policy.

This page on the web

This policy is hosted on wilmoth.engineering. Visiting it is an ordinary web request. The host may record request data (IP address, browser, page requested) so the site stays up.

Children

Opening Lodebook asks for no personal information. The collected-data-type list is empty.

Changes

When Lodebook’s data handling changes, this page is updated.

Contact

Questions: privacy@wilmoth.engineering
